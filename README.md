# Diário de treino do Josias

Extraia o ZIP. Em um repositório GitHub, envie os arquivos e a pasta img para a raiz da branch main. Em Settings → Pages → Deploy from a branch, escolha main e /(root). Aguarde a conclusão do deploy e compartilhe a URL exibida em Pages.
No Android, abra o endereço no Chrome e escolha Instalar aplicativo ou Adicionar à tela inicial. No iPhone, abra no Safari e use Compartilhar → Adicionar à Tela de Início. Abra uma vez com internet para carregar o conteúdo offline.
Escolha a sessão e a data, abra um exercício e registre cada série. A conclusão é manual e permite sessões parciais. Consulte ou reabra o treino em Histórico. Os dados ficam no navegador ou app instalado. Use sempre o mesmo acesso. Limpar os dados do site remove os registros. Não há sincronização entre celulares.
As fotos estão incluídas em img. Fonte: https://github.com/yuhonas/free-exercise-db . Para adaptações, o guia identifica a variação fotografada.
